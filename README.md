## 🛠️ Requirements to Run
* **Operating System:** Windows 10 / 11
* **Java Runtime:** Java JRE 8 (1.8.0) or higher installed on your machine
* **Database:** MySQL / MariaDB server running locally

---

## 📂 Included Modules
1. **School Management System:** Student and faculty record management, GUI data entry forms, and database persistence.
2. **Library Management System:** Book tracking and issue system.
3. **Restaurant Billing System:** Orders and bill calculation interface.
4. **Calculator:** A system for calculation using arithmetical operators.
5. **Data Fetching:** A system for data extraction from table using SQL interfaces.
